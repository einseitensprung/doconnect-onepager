# doconnect One-Pager

Ein heller, professioneller One-Pager auf Basis der Inhalte von [doconnect.at](https://www.doconnect.at/) – Marken-Blautöne, Original-Logo, statisches HTML/CSS ohne Build-Schritt.

**Live-Preview (GitHub Pages):** https://einseitensprung.github.io/doconnect-onepager/

**Preview (Claude Artifact):** https://claude.ai/code/artifact/1cbd25cb-6171-4f96-9eaa-eb7518a6fd32

## Inhalt

- `index.html` – die komplette Seite (Hero, Leistungen, Anspruch, Pakete, Kundenstimmen, Kontakt, Footer)

## Lokal öffnen

Einfach `index.html` im Browser öffnen – keine Abhängigkeiten, kein Build-Prozess nötig.
